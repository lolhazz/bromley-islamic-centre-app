Bromley Islamic Centre app editor

Changes appear in the app within a minute of publishing.

Jumu’ah times

Shown on the Prayer tab. Write times like “1:15 pm”.

Iqamah times

When the jama’ah starts, for the five daily prayers. Use minutes after the adhan, or fill in a fixed time (24-hour, like 13:30), which wins if both are set. Changes reach the Prayer tab, the widgets and the alerts.

Venue notice

The banner on the Prayer tab, for example the current temporary venue.

Announcements

Newest first.

Events

Shown under “Coming up” on the What’s on tab.

Ramadan

Leave empty to use the calendar calculation.
